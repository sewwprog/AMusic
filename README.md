# AMusic Desktop

Музичний застосунок для Windows на React + TypeScript + Tauri 2.

## Можливості
- Локальна бібліотека MP3/M4A, плейлисти, улюблені, черга, пошук
- Плеєр, еквалайзер (п’ять частотних смуг), Replay
- Темна/світла тема у стилі Telegram Desktop та iOS
- **«Музика для всіх»**: авторизація через Supabase, перегляд спільного каталогу, завантаження аудіо в локальну бібліотеку, публікація власної або дозволеної музики
- Локальні файли й статистика зберігаються в IndexedDB поточного профілю застосунку. Не видаляй дані програми без резервної копії.

## Запуск без Rust
Можна перевірити інтерфейс у браузері. Потрібен Node.js.

1. Завантаж **Code → Download ZIP** з репозиторію.
2. Розпакуй архів.
3. Відкрий PowerShell у папці з `package.json`:

```powershell
npm install
npm run dev
```

Відкрий адресу, яку показав Vite (зазвичай http://localhost:5173).

> Примітка: режим браузерного запуску не створює .exe. Для `npm run tauri dev` або `npm run tauri build` потрібні Rust/Cargo, MSVC C++ Build Tools та WebView2.

## Community
Використовує існуючу Supabase-базу AMusic (URL та **публічний** publishable key у `src/community.ts`, без service-role секретів). Таблиця `amusic_public_tracks` та приватний bucket `amusic-community-audio` мають існувати з відповідними RLS-політиками.

Використовуйте той самий email і пароль, що й в AMusic на телефоні. Аудіофайли для публікації — MP3/M4A/AAC, не більше 25 МБ. Публікуйте лише власні записи або записи, на які маєте дозвіл. Для завантаження аудіо використовується автентифікований доступ до приватного bucket.

Сесія входу наразі зберігається тільки в sessionStorage (на час поточного сеансу програми). Якщо сесія закінчилася, увійдіть повторно.

## Межі версії
Поки що немає автоматичної синхронізації приватної локальної бібліотеки з iPhone, перенесення «Мого простору», Spotify або YouTube. Це окремі iOS-функції. Обкладинки, редагування метаданих і мобільна профільна кастомізація ще потребують адаптації.
